# Security reporting

This is a preview project without an independent security audit. Report suspected
security vulnerabilities privately to rares@webleaf.ro. Describe the affected version, impact and a minimal reproduction;
do not include other people's screen contents, credentials or device private keys.
Do not disclose exploitable details in a public issue before the maintainer has
had a reasonable opportunity to investigate and coordinate a fix.

DeskLink requires host approval for each session. Public numeric IDs are addresses,
not passwords. Do not approve unknown people. Windows secure/elevated desktops
and Linux Wayland control are not supported. Keep normal OS security protections
enabled when evaluating preview builds.
