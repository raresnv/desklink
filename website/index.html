Verify a download ↗

A few things
to know.

What to expect when you open DeskLink for the first time.

Do I need an account or a setup code?+

No. The downloaded app connects to the public relay and registers its computer ID automatically. Open DeskLink on both computers, enter the host’s ID, and wait for their approval.

Does it work outside my local network?+

Yes. Both computers connect outward to the public relay over an encrypted connection, so you don’t need to forward ports on your router. Both apps need to stay open and online. Restricted networks must allow outgoing encrypted connections on TCP port 9443.

Installing on a Mac+

Download and unzip the Apple Silicon package, then drag DeskLink.app into Applications and open it normally. This preview has a development signature. Mac distribution signing and Apple notarization are pending, so macOS may warn or block opening it. Keep normal security settings enabled. Screen Recording and Accessibility permission are needed when you approve sharing and control. These permissions don’t replace approval for each session.

This package is for Apple Silicon Macs. An Intel Mac package is not included in this release.

Installing on Windows+

Extract the ZIP and open desklink.exe. Keep any included files together. Publisher signing is pending; these Windows preview builds are unsigned. Windows may show a reputation warning or block opening them. Keyboard and mouse control supports the ordinary signed-in desktop, not security prompts or locked desktops.

An experimental Windows ARM64 preview is also available. The latest complete two-way input test used the x64 build in a Windows 11 ARM virtual machine.

Installing on Linux+

This release is an ARM64 build for Ubuntu 24.04 with an X11 session. Extract the archive and run ./desklink. The included README lists the desktop libraries to install. Wayland control and an x64 Linux download are not included in this preview.

What does the relay keep?+

The relay stores public device keys and their IDs, and uses short-lived network-address records to limit new registrations. Screen and keyboard/mouse data are encrypted between the computers. Short IDs trust the relay directory on first contact; the app remembers approved peer keys to detect later changes.

What has been tested?+

Mac and Windows screen sharing and keyboard/mouse control were checked in both directions through the public relay. The Windows x64 preview streamed above 30 fps in a Windows 11 ARM virtual machine; performance varies with your computer, desktop contents and internet connection. The Linux 0.3.1 build passed its library tests; a fresh two-way Linux GUI retest is pending. This remains a limited-capacity preview without an independent security audit or production-scale guarantee.
