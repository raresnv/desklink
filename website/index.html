Verify a download ↗

A few things
to know.

What to expect when you open DeskLink for the first time.

Do I need an account or a setup code?+

No. The downloaded app connects to the public relay and registers its computer ID automatically. Open DeskLink on both computers, enter the host’s ID, and wait for their approval.

Does it work outside my local network?+

Yes. Both computers connect outward to the public relay over an encrypted connection, so you don’t need to forward ports on your router. Both apps need to stay open and online. Restricted networks must allow outgoing encrypted connections on TCP port 9443.

Installing on a Mac+

Download and open the Apple Silicon DMG. Quit any older DeskLink copy, then drag DeskLink.app onto the Applications shortcut in the disk image. Replace the old app if asked. Eject the DMG and open DeskLink from Applications. The 0.3.3 app and DMG are Developer ID signed by Overtex Core Solutions SRL and notarized by Apple, with stapled tickets. It opens with normal macOS security settings. Replace older copies with this download. Install 0.3.3 on both Macs for Sharp (up to 2560 pixels) and Original / Retina (up to 4096 pixels). The viewer also offers Fit and 100% zoom with scroll bars. Original uses more bandwidth and may lower frame rate; older peers retain their previous stream quality. Screen Recording and Accessibility permission are needed when you approve sharing and control. These permissions don’t replace approval for each session.

This package is for Apple Silicon Macs. An Intel Mac package is not included in this release.

Installing on Windows+

Run the setup EXE. It installs for your Windows account, adds Start menu shortcuts and provides an uninstaller, without requiring administrator access. Close DeskLink before upgrading or removing it. Open DeskLink from the Start menu after installation. The uninstaller keeps your computer ID, settings and unrelated files. The installer adds no startup entry, background service or firewall opening. Windows publisher signing is not configured; the installer, app and uninstaller are unsigned previews. Windows may show a reputation warning or block opening them. Keyboard and mouse control supports the ordinary signed-in desktop, not security prompts or locked desktops.

An experimental Windows ARM64 installer is also available. The latest complete two-way input test used the x64 build in a Windows 11 ARM virtual machine.

Prefer a portable download? ZIP previews are available for Windows x64 and experimental ARM64. Extract all files and open desklink.exe. These are also unsigned.

Installing on Linux+

This release is an ARM64 build for Ubuntu 24.04 with an X11 session. Extract the archive and run ./desklink. The included README lists the desktop libraries to install. Wayland control and an x64 Linux download are not included in this preview.

What does the relay keep?+

The relay stores public device keys and their IDs, and uses short-lived network-address records to limit new registrations. Screen and keyboard/mouse data are encrypted between the computers. Short IDs trust the relay directory on first contact; the app remembers approved peer keys to detect later changes.

What has been tested?+

The exact public Mac 0.3.3 DMG and contained app pass signature, Apple notarization, stapled-ticket and Gatekeeper checks. The read-only disk image, Applications shortcut and unchanged app executable were verified. The app is the same 0.3.3/build 9 previously distributed in a ZIP. Its downloaded app opens under normal macOS security settings, retains its computer ID and connects to the public relay. All three quality modes, Fit, 100% zoom and panning were checked in the downloaded viewer through the public relay using generated images. The downloaded host also passed a real-screen, view-only check through the public relay to a client on the same Mac: Sharp at 2560 × 1663 averaged about 34 fps, and Original at 3600 × 2338 about 19 fps in short measurement windows. A second physical Mac still needs to be updated and checked. Full two-way keyboard/mouse and fresh permission-onboarding checks on 0.3.3 remain pending.

The Windows x64 and experimental ARM64 installers passed install, reinstall and uninstall checks in a Windows 11 ARM virtual machine, including ID/settings retention, shortcut registration and protection of unrelated files. They install for the current user without administrator rights. The app executables are unchanged from the earlier ZIP downloads.

Windows 0.3.3 passed 44 native unit tests and native ARM64 capture/JPEG decoding at all three resolutions in a Windows 11 ARM virtual machine. Both public archives and executable versions were verified inside Windows. Full two-way keyboard/mouse checks on 0.3.3 remain pending; ARM64 is experimental.

The earlier 0.3.1 Mac and Windows previews were checked for screen sharing and keyboard/mouse control in both directions through the public relay. The Windows x64 preview streamed above 30 fps in a Windows 11 ARM virtual machine; performance varies with your computer, desktop and connection. The unchanged Linux 0.3.1 download retains its earlier verification scope. This remains a limited-capacity preview without an independent security audit or production-scale guarantee.
